# वैदिक जन्म कुंडली (Hindi Vedic Janam Kundali)

एक आधुनिक, सुंदर एवं प्रामाणिक **वैदिक जन्म कुंडली (Janam Kundali) वेब एप्लिकेशन**। यह एप्लिकेशन पाइथन फ्लास्क (Python Flask) और विश्व प्रसिद्ध खगोलीय लाइब्रेरी **स्विस एफिमेरिस (Swiss Ephemeris / pyswisseph)** पर आधारित है।

---

## 🌟 प्रमुख विशेषताएं (Key Features)

1. **सटीक खगोलीय एवं वैदिक गणनाएं**:
   - **लाहिड़ी अयनांश (Lahiri / Chitrapaksha Ayanamsa)** और निरयण (Sidereal) राशि चक्र।
   - **सम्पूर्ण राशि भाव (Whole-Sign Houses)** पद्धति: लग्न जिस राशि में हो, वही प्रथम भाव बनता है।
   - **लग्न एवं ९ ग्रह**: सूर्य, चन्द्र, मंगल, बुध, गुरु, शुक्र, शनि, राहु (Mean Node) तथा केतु (राहु + १८०°)।
   - प्रत्येक ग्रह की राशि, अंश, कला, विकला, नक्षत्र (१-२७), चरण/पद (१-४), भाव संख्या और मार्गी/वक्री गति।
   - **विंशोत्तरी महादशा चक्र**: जन्म कालीन चंद्रमा के नक्षत्र भोग्य अंश के आधार पर प्रथम महादशा का भुक्त/भोग्य शेष काल, उसके बाद १२० वर्ष के संपूर्ण चक्र में सभी ९ ग्रहों की महादशाओं की सटीक प्रारंभ एवं समाप्ति तिथियां (वर्तमान सक्रिय महादशा की पहचान सहित)।

2. **स्थान एवं समय क्षेत्र (Timezone) प्रबंधन**:
   - **OpenStreetMap Nominatim** द्वारा स्वतः स्थान खोज (Place Autocomplete)।
   - अक्षांश (Latitude), देशांतर (Longitude) और समय क्षेत्र (IANA Timezone - डिफ़ॉल्ट `Asia/Kolkata`) का स्वतः भरण।
   - पाइथन के मानक `zoneinfo` मॉड्यूल द्वारा स्थानीय समय को UTC में रूपांतरण, जिससे पुराने ऐतिहासिक वर्षों (जैसे स्वतंत्रता पूर्व भारत में वॉर डेलाइट टाइम +06:30) की सटीक गणना होती है।

3. **विशिष्ट एवं आकर्षक डिजाइन (Distinctive Vedic Design)**:
   - पूरी तरह स्वतंत्र, मौलिक और गरिमामयी डिज़ाइन (AstroSage या Prokerala की नकल नहीं)।
   - प्रामाणिक देवनागरी टाइपोग्राफी: शीर्षकों के लिए **Tiro Devanagari Hindi** और मुख्य पाठ के लिए **Noto Sans Devanagari**।
   - पूर्णतः रेस्पॉन्सिव (मोबाइल-फर्स्ट) तथा सुगम (Accessible Visible Focus States)।
   - हिंदी में स्पष्ट एवं सुधारात्मक त्रुटि संदेश (Actionable Hindi Error Messages)।

4. **आउटपुट एवं प्रिंट सुविधा**:
   - शुद्ध **SVG उत्तर भारतीय हीरा कुंडली (North Indian Diamond Layout)**, जिसमें सभी १२ भाव, राशि संख्याएं तथा देवनागरी में ग्रहों के नाम व वक्री चिह्न `(व)` अंकित हैं।
   - नवग्रह स्पष्ट स्थिति सारणी और विंशोत्तरी महादशा चक्र सारणी।
   - **प्रिंट-फ्रेंडली लेआउट (`@media print`)**: "प्रिंट / PDF सहेजें" बटन द्वारा केवल कुंडली और आवश्यक सारणियां साफ़-सुथरे रूप में A4 पेपर पर प्रिंट या PDF होती हैं।

5. **एसईओ एवं ज्ञानवर्धक सामग्री**:
   - हिंदी शीर्षक, मेटा विवरण, सिमेंटिक `h1` तथा **JSON-LD FAQPage Schema**।
   - मूल शैक्षिक लेख: लग्न, १२ राशियां, १२ भाव, २७ नक्षत्र, ४ चरण और विंशोत्तरी दशा का महत्व।

6. **पारदर्शिता एवं नैतिक सिद्धांत**:
   - स्पष्ट अस्वीकरण: *"यह गणना पारंपरिक वैदिक ज्योतिष सिद्धांतों पर आधारित है, यह कोई वैज्ञानिक प्रमाण नहीं है।" (Ye parampara par aadharit hai, vaigyanik pramaan nahi hai.)*
   - **शून्य भय-व्यापार (Zero Fear-Based Upsell)**: कोई काल सर्प दोष, मांगलिक भय, महंगे रत्न बेचना या कर्मकांडीय पूजा बेचने का विज्ञापन नहीं।

## 🚀 इंस्टॉलेशन एवं चलाने की विधि (Run Steps)

### १. आवश्यकताएं (Prerequisites)
- Python 3.10+ (या `uv` पैकेज मैनेजर)
- Git (वैकल्पिक)

### २. वर्चुअल एनवायरनमेंट तैयार करें
```bash
# uv के माध्यम से (अनुशंसित - तीव्र एवं सुगम)
uv venv --python 3.11 .venv
.venv\Scripts\activate      # Windows (PowerShell: .venv\Scripts\Activate.ps1)

# या मानक Python venv के माध्यम से
python -m venv .venv
.venv\Scripts\activate
```

### ३. आवश्यक लाइब्रेरी इंस्टॉल करें
```bash
pip install -r requirements.txt
```

### ४. एप्लिकेशन चलाएं
```bash
python app.py
```
एप्लिकेशन अब **http://127.0.0.1:5000** पर उपलब्ध होगा। किसी भी ब्राउज़र में यह लिंक खोलें।
